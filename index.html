📖 Detailed Step-by-Step User Guide

Step 1: Paste Original Text (Version A) Into the Left Pane · [Original Text Editor (#textA)]Paste or type the baseline version of your contract clause, code snippet, or prose into `#textA`.✓ Result: Original text is loaded in local browser memory.
Step 2: Paste Revised Text (Version B) Into the Right Pane · [Revised Text Editor (#textB)]Paste the updated or redlined text into `#textB`.✓ Result: Both versions are ready for Longest Common Subsequence (LCS) comparison.
Step 3: Click Compare Texts to Inspect Word-Level Highlights · [Compare Button (#btnDiff) & Diff Output (#diffOut)]Click **Compare (`#btnDiff`)**. Inspect `#diffSummary` (added/removed line counts and similarity percentage) and `#diffOut`, where intra-line word changes are highlighted in green (`.w-add`) and red (`.w-del`).✓ Result: Subtle single-word edits (like `30 days` → `45 days`) stand out immediately.
Step 4: Export Standard Unified .diff Patch File · [Download .diff Button (#btnDl)]Click **Download .diff (`#btnDl`)** to save a standard unified diff file with `-` and `+` hunks.✓ Result: Standard `.diff` patch file downloaded locally.

🎛️ UI Controls & Shortcuts Reference

  • Version A (`#textA`) & Version B (`#textB`) — Side-by-side text areas for original and revised text.
  • Compare (`#btnDiff`) — Runs the deterministic LCS diff algorithm with intra-line word highlighting.
  • Diff Summary (`#diffSummary`) & Output (`#diffOut`) — Shows similarity score, added/removed counts, and color-coded word diffs.
  • Download .diff (`#btnDl`) — Exports a standard unified `.diff` text file.

💡 Pro Tips & Real-World Workflows

  • Use Text Diff before signing a counter-party's 'clean final PDF' of an NDA or MSA: copy the text from your draft into `#textA` and the text from their PDF into `#textB` to catch silent edits.
  • AI agents can also call this exact diff engine deterministically via `POST https://navigatorslab.com/tools/mcp` (`text_diff` tool).
  • You can pre-populate inputs via URL parameters (`textdiff.html?a=...&b=...`).
